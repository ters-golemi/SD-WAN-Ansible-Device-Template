# Quick Reference Guide

## Command Quick Reference

### Initial Setup

```bash
# Clone the repository
git clone https://github.com/ters-golemi/SD-WAN-Ansible-Device-Template.git
cd SD-WAN-Ansible-Device-Template

# Update inventory with your SD-WAN Manager details
vi inventory/hosts.yml

# Update device variables
vi vars/device_vars.yml
```

### Running Individual Exercises

```bash
# Exercise 1: Check for compatible device templates
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml

# Exercise 2: List vSmart controllers  
ansible-playbook -i inventory/hosts.yml playbooks/2_list_vsmart_controllers.yml

# Exercise 3: Attach template to vSmart controller
ansible-playbook -i inventory/hosts.yml playbooks/3_attach_template.yml

# Exercise 4: Verify attachment and sync status
ansible-playbook -i inventory/hosts.yml playbooks/4_verify_attachment.yml
```

### Running Complete Workflow

```bash
# Run all exercises in sequence
ansible-playbook -i inventory/hosts.yml playbooks/complete_workflow.yml
```

### Using Ansible Vault (Recommended for Production)

```bash
# Create encrypted vault file
ansible-vault create inventory/vault.yml

# Edit existing vault file
ansible-vault edit inventory/vault.yml

# Run playbook with vault
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml --ask-vault-pass

# Or use vault password file
echo "your_vault_password" > .vault_pass
chmod 600 .vault_pass
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml --vault-password-file .vault_pass
```

### Optional: Detach Device from Template

```bash
# WARNING: This will remove vManage-managed configuration
ansible-playbook -i inventory/hosts.yml playbooks/detach_template.yml
```

## Common Variables

### Inventory Variables (inventory/hosts.yml)

| Variable | Description | Example |
|----------|-------------|---------|
| `vmanage_host` | SD-WAN Manager IP/hostname | `198.18.1.10` |
| `vmanage_port` | SD-WAN Manager HTTPS port | `443` |
| `vmanage_username` | Username for authentication | `admin` |
| `vmanage_password` | Password for authentication | `admin` |
| `validate_certs` | SSL certificate validation | `no` (lab only) |

### Device Variables (vars/device_vars.yml)

| Variable | Description | Example |
|----------|-------------|---------|
| `template_name` | Name of the device template | `vSmart_Template` |
| `device_uuid` | UUID of the vSmart controller | `00000000-0000-0000-0000-000000000001` |
| `device_vars.system_host_name` | Device hostname | `vsmart-1` |
| `device_vars.system_system_ip` | Device system IP | `1.1.1.1` |
| `device_vars.system_site_id` | Device site ID | `100` |

## Output Files

The playbooks generate the following output files in `/tmp/`:

| File | Description | Generated By |
|------|-------------|--------------|
| `/tmp/vsmart_templates.json` | List of vSmart-compatible templates | Exercise 1 |
| `/tmp/vsmart_controllers.json` | Detailed vSmart controller information | Exercise 2 |
| `/tmp/vsmart_inventory.txt` | Simplified vSmart inventory | Exercise 2 |
| `/tmp/vsmart_running_config.json` | Running configuration | Exercise 4 |
| `/tmp/vsmart_verification_report.txt` | Verification report | Exercise 4 |

## Troubleshooting Commands

```bash
# Test connectivity to SD-WAN Manager
ping <sdwan-manager-ip>
curl -k https://<sdwan-manager-ip>

# Validate YAML syntax
python3 -c "import yaml; yaml.safe_load(open('inventory/hosts.yml'))"

# Check Ansible version
ansible --version

# Syntax check a playbook
ansible-playbook --syntax-check playbooks/1_check_device_templates.yml -i inventory/hosts.yml

# Run playbook with increased verbosity
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml -v
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml -vv
ansible-playbook -i inventory/hosts.yml playbooks/1_check_device_templates.yml -vvv
```

## API Endpoints Used

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/dataservice/template/device` | GET | List all device templates |
| `/dataservice/device` | GET | List all devices |
| `/dataservice/template/device/config/attachfeature` | POST | Attach device to template |
| `/dataservice/device/action/status/{id}` | GET | Check action status |
| `/dataservice/template/config/attached/{uuid}` | GET | Get template config status |
| `/dataservice/template/config/running/{uuid}` | GET | Get running configuration |
| `/dataservice/template/config/device/mode/cli` | POST | Detach device from template |

## Expected Results

### Exercise 1 Output
- Total number of device templates
- List of vSmart-compatible templates
- Template IDs and names

### Exercise 2 Output
- Number of vSmart controllers found
- For each vSmart: hostname, system IP, UUID, status, template attachment

### Exercise 3 Output
- Confirmation of template attachment initiation
- Action ID for monitoring
- Device and template information

### Exercise 4 Output
- Template attachment status (YES/NO)
- Configuration sync status (IN SYNC/NOT IN SYNC)
- Device health status (HEALTHY/UNHEALTHY)
- Overall verification result (PASSED/FAILED)
